# User Suggestions

> A holding area for questions and ideas the user wants added to the app later.
> **Future-facing only** — once an item is implemented, it is removed from this file to keep it clean.

---

## How this file is managed (rules for the agent)

1. **Image drop = add verbatim.** When the user provides image(s) and references `user-suggestions.md` with no other context, simply transcribe each **question and its response options** into this file. Do not implement anything, do not add correct answers or commentary unless asked.
2. **Place sensibly.** Group new items under an appropriate heading (by track / topic). If nothing fits, drop them under "General / Unsorted".
3. **Correct answers & section mapping are decided at implementation time**, not here, unless the user provides them.
4. **Remove on implementation.** When items are built into the app, delete them from this file so it only ever contains pending work.
5. **Keep it clean and terse.** This is a queue, not a log.
